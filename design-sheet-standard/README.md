# 角色与道具设定图规范

适用于所有后续项目。收到生成设定图的任务后，按对象选用对应规格；当次明确指定的要求优先。

## 角色 → 角色设定图

以用户提供的[领班角色设定图](./character-sheet-reference.png)为排版模板。每个角色的脸、体型、服装、配件和配色以该角色自己的参考图及项目设定为准。

- 横版画布，干净浅底，保留清晰留白，标签简洁。
- 左侧并排放全身正面、侧面、背面。自然站姿，三视图比例一致，头顶与脚底基线对齐，全身入画。
- 右侧用简洁网格放若干面部、头部和关键肢体特写。可选用代表性的面部角度或表情，并按角色补充手部、机械关节、服饰或配件等辨识度高的细节。
- 交付前核对各视角中的脸、发型、体型、服装、配件、位置和配色。

## 道具 → 标准三视图

- 默认正视、侧视、俯视，采用正投影，三视角统一尺度并对齐布局。
- 核对轮廓、结构、材质、配色和零件位置。其他视角或局部细节按当次项目要求补充。
